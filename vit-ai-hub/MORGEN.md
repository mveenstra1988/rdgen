# Morgen: 1 pakket, klaar

## Wat je draait
1. Unzip `dist/VIT-AI-Hub-0.8.1-mac.zip`
2. Eventueel: `xattr -dr com.apple.quarantine "VIT AI Hub.app" hub`
3. Dubbelklik **VIT AI Hub.app** → wizard
4. Stap import: chats **én** Claude/Cursor skills → worden ook agents (bots)
5. Tab **Agent teams** voor webdesign-/app-teams

## Skills / bots
- Skills: `~/.claude/skills`, project `.claude/skills`, Cursor skills
- Bots = agents in Agent teams (niet Claude.ai cloud-bots / Custom GPTs)
