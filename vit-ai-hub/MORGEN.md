# Morgen — VIT AI Hub 1.0

1. Unzip `dist/VIT-AI-Hub-1.0.0-mac.zip`
2. `xattr -dr com.apple.quarantine "VIT AI Hub.app" hub` indien macOS klaagt
3. Dubbelklik **VIT AI Hub.app**
4. Wizard → **Migreer ALLES nu**

## Wat je krijgt
- Claude + ChatGPT + Cursor data/settings/MCP/rules/prompts/skills → hub
- MCP-tools in chat (`mcp_list_*` / `mcp_call_tool`)
- Agent teams (webdesign, apps, self-improve)
- Studio **Self-improve** — hub past zichzelf aan op verzoek
- Privacyfilter op alles naar cloud

## Optioneel
- `bash hub/scripts/install-bridge-mac.sh` voor Claude/ChatGPT-abo bridge
- LM Studio light model laden
- Cursor base URL: `http://127.0.0.1:8787/v1`
