# Morgen: 1 pakket, klaar

## Wat je draait
1. Unzip `dist/VIT-AI-Hub-0.7.0-mac.zip` (of de artifact)
2. Eventueel: `xattr -dr com.apple.quarantine "VIT AI Hub.app" hub`
3. Dubbelklik **VIT AI Hub.app**
4. Klik **Alles nu regelen**

## Daarna (software / design / Cursor eruit)
- Studio **Software** + workspace `~/Projects/...` voor code
- Studio **Webdesign** voor sites zonder Figma
- Knop **Penpot** of `bash hub/scripts/install-penpot-mac.sh` (Figma-alt)
- Knop **Continue→hub** → VS Code/Zed i.p.v. Cursor

Zie `docs/EXIT.md` en `docs/STUDIO.md`.
