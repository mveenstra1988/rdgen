# Morgen: 1 pakket, klaar

## Wat je draait
1. Unzip `dist/VIT-AI-Hub-0.7.1-mac.zip`
2. Eventueel: `xattr -dr com.apple.quarantine "VIT AI Hub.app" hub`
3. Dubbelklik **VIT AI Hub.app**
4. Volg de wizard (8 stappen): lokaal → OpenRouter/DeepSeek → OmniRoute → Claude/GPT-login → Cursor → import → klaar

De wizard opent login/key-pagina’s voor je. Claude/ChatGPT-abo: één keer OAuth in de bridge (CLIProxyAPI).

## Daarna
- Alles in één GUI op http://127.0.0.1:8787
- Cursor base URL: `http://127.0.0.1:8787/v1`
