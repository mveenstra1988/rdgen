Welkom bij AI Hub

We leiden je door login, keys, import en Cursor. 1 / 8

    Wat je krijgt

    Één app met privacyfilter: lokale modellen (M5 Max), Claude + ChatGPT via je abo, Cursor erdoorheen, plus OpenRouter (gratis), DeepSeek, OmniRoute en Grok.

    • Klant-PII wordt geblokkeerd vóór cloud
    • Oude chats/kennis overzetten van dezelfde Mac
    • Modelpicker i.p.v. losse websites
    Laden…

    Je kunt stappen overslaan; lokaal werkt ook zonder cloud-keys.

    1 · Lokaal (M5 Max 128GB)

    LM Studio met MLX. Advies: light MoE ~20GB resident, ~48GB vrij voor apps. Heavy alleen on-demand.

    Start LM Studio → Local Server aan → model laden.

    2 · OpenRouter + DeepSeek + gratis

    Eén OpenRouter-key geeft gratis modellen (Llama, Gemma, Qwen, DeepSeek free) én betaalde. Of plak een native DeepSeek-key.

    Gratis-modellen verschijnen in de picker als OpenRouter-key gezet is.

    3 · OmniRoute (optioneel)

    Draait lokaal op :20128 en bundelt nog meer providers/gratis routes. Mag leeg blijven.

    Status volgt bij “Controleer verbindingen”.

    4 · Claude + ChatGPT abo (inloggen)

    Je abonnementen blijven van jou. De hub praat via een lokale bridge (:8317), niet rechtstreeks met hun websites.

    1. Installeer/start CLIProxyAPI (bridge) — knop hieronder
    2. Log daar één keer in met Claude / ChatGPT (OAuth)
    3. Plak eventueel de bridge API key hier

    Na OAuth in de bridge staan Claude/GPT-modellen in de picker.

    5 · Cursor door de privacyfilter

    In Cursor → Settings → Models:

    http://127.0.0.1:8787/v1

    OpenAI API Key = je hub-token (wordt hieronder getoond na setup). Zo gaan Cursor-requests door dezelfde filter.

    6 · Alles overzetten

    Importeert Cursor, Claude Code/Cowork, ChatGPT-cache/fragmenten en export-zips uit Downloads. Live-lees van open apps vraagt Toegankelijkheid.

    Dit kan even duren bij veel chats.
